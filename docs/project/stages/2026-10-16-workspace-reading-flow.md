## 范围

- 复用工作台、消息、调查进展和原输入框，减少重复标题、卡片边界与多余间距，不新建栏目或依赖。
- 当前程序及所属电脑仍直接可辨认，具体连接和未验证范围按需查看，不按名称推断整个程序正常。
- 未完成检查的继续入口直接定位输入框，不自动发送、不清空草稿；无法确认程序时仍暂停发送。
- 保留已核对回答、未核对原文、技术证据、停止确认、模型用量提醒和批准边界。
- 只修改项目并使用本地隔离固定数据；不更新 Mac，不调用 Qwen，不创建真实访问、批准或网络写请求。

## 顺序与完成标准

先固定继续入口和内容边界，再精简布局；最后在桌面、窄屏、键盘及双浏览器验证，不只比较配色。

- [x] 继续入口定位原输入框并保留草稿，不产生写请求；发送和停止仍只有明确操作才执行。
- [x] 程序、电脑、具体连接、未知情况、已核对内容与批准边界均保留，技术信息按需查看。
- [x] 组件、格式、类型、构建、体积与必要双浏览器验证通过，无严重无障碍问题或横向溢出。
