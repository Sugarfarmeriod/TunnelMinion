# 服务、调查与申请之间的往返体验

- 状态：已完成（本阶段最新完整 CI 通过并合并后生效）
- 主写分支：`feature/service-return-path`
- 基线：`8bfafad285fe5b556b56176dcb68b018332656a5`

## 用户目标

从服务进入调查后，能辨认正在查看的对象；查看申请或已有请求后，能返回调查和原服务，不重新翻找。
不增加首页栏目，不改变请求、批准、执行和清理的权限，不调用真实模型或部署到 Mac。

## 行为与边界

- 调查结果先显示设备与服务名称，只有精确、唯一匹配且新鲜的名称才作为当前名称展示。
- 同一服务仍在清单时，提供“返回这项服务”；返回时展开所属设备并定位到服务。无名称时定位完整技术清单，不凭端口猜名称。
- 服务消失、身份重复或所属设备不一致时，保留历史调查，明确无法定位，不生成错误返回或处理入口。
- “返回最近变化”回到对应事件；进入调查和申请时，键盘位置移到相应标题。浏览器前进、后退及返回地址重载可用。
- 申请目标不可用时仍保留“返回调查结果”；已有请求的来源调查入口直接可见，无需展开技术记录。
- 复用原生 details、同源路由及已有持久化来源字段，无新依赖、全局导航系统或额外模型请求。
