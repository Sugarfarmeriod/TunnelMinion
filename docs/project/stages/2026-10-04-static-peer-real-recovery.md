- 状态：`进行中，停止原因误报已修正，实际恢复等待管理员只读状态权限`

- 基线：`c7a8585126f3b08a3815c9941993d0d7d0091fa6`

## 用户影响与范围

未接入服务目录时，可显式指定一个已授权静态对端及 TCP 端口，让普通后台观察器发现网络监听变成
回环监听的变化并自动调查。缺配置或 `enabled=false` 时不查询远端，不改变原有行为。
用户已授权补该产品接入，并在隔离双机上验收；恢复操作仍由用户在目标页面逐次批准。

## 接入与证据边界

在独立数据目录新增非秘密 `peer-observation.json`：

```json
{"enabled": true, "node_id": "node_ab20a99d6ae6451690076c561e4b7683", "port": 43123}
```

节点 ID 为本次隔离 Mac 身份示例，使用前必须核对。只复用 `gateway.json` 的显式对端、凭据与只读授权，
此配置本身不授予工具权限。现有监听工具返回完整列表，观察器只保留指定 TCP 端口；不新增端口扫描。
后台每 30 秒观察，连续两次变化才产生事件，正常刷新不调用模型。页面来源标记为“显式对端只读观察”。
观察身份由节点、协议和指定端口决定，监听地址改变不改变身份；不改其他观察路径的端点 ID 规则。
启用该模式时只对指定端口触发自动调查，完整总览和历史快照仍保留；切换范围重新建立观察基线。
首次未知变成回环监听不冒充网络到回环变化；无权限、断连、超时或残缺结果保留旧事实并标记陈旧。
静态观察不能与目录观察同时启用，避免同一节点双来源。配置修改后需重启隔离本机程序。

### 只读复核与停止原因修正
