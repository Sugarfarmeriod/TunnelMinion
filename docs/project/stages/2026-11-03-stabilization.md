## 稳定期之后

主人已确认留到稳定期结束后再做的事，按计划顺序排列。

1. **临时访问做完整**。目标场景：朋友把只听自己本机（127.0.0.1）的小应用发给主人。主人在地图上点开朋友电脑上的这个程序，或者在对话里问"为什么打不开"；Agent 说明它只听本机，并提出临时访问方案。朋友批准、主人确认后，主人这边马上能打开。需要补的：
   - Windows 也能开临时入口；
   - 常驻启动的网关默认就能接住申请，"可申请的电脑"只列出真正接得住的电脑；
   - "我的电脑"之间默认可申请（#273 草稿）；
   - 朋友也能申请，每次都要朋友批准；
   - 地图服务面板和对话里能直接提出申请；
   - 支持长连接（WebSocket），让 Streamlit、Gradio、Vite 这类 AI 小应用能正常用。
2. **自动发现，点一下加好友**。同一个网里装了 TunnelMinion 的电脑自动出现在地图上，不用再复制、发送、输入邀请码。"在网里"只用来发现，不用来授权：
   - 加朋友：主人点"加为朋友"，对方电脑弹出确认，对方同意才算数；
   - 加自己的电脑：由一台已经在用的"我的电脑"点"这是我的电脑"确认，新电脑不能自己声称是主人的；
   - 可选：两边显示同一串短码，看一眼一致再同意，防止网里有人冒名；
   - 发现方式待查：探测私网网段里的 TunnelMinion 端口、局域网 mDNS、读 WireGuard 对端列表（Windows 上可能要管理员权限，尚未核实）。
3. 地图上显示两台电脑之间的多条网络路径（例如 WireGuard 之外的 n2n），并按实测延迟摆放：现在电脑之间的距离是排版用的固定值，地图不测延迟。要做的：
   - 定期测每条路径的往返延迟，连线上标出来；
   - 电脑之间的距离跟着延迟变，延迟低的靠得近；
   - 延迟抖动时位置平滑过渡，不跳来跳去，常见窗口仍一屏看全。
4. Windows 开机自启：电脑重启或程序被关掉后能自己起来，不用手动启动。
5. **显示用了多少 token**。每次提问的结果里已经带着输入、输出、合计 token（`agent/runtime.py`），网页也收到了，但对话界面没显示。要做的：
   - 每个回答底下显示这次用了多少 token、调用了几轮模型；
   - 思考过程中实时更新用量；
   - "设置"里按天看总用量；
   - 借给别的电脑用的模型按 token 记账（现在只按天记次数）。
