# 已授权远端服务的自动归属

- 状态：`已完成`；仅在本阶段 PR 最终完整 CI 通过并合并后生效
- 主写分支：`feature/remote-service-identity`
- 基线：`fabdb046d10d4119091ebbbd0975799d4637043c`
- 对应总流程：已授权远端自动归属；具体用途识别仍为条件触发

## 结果与用户影响

不要求用户逐个挑选远端端口。对目录中近期在线且已有 Gateway 只读授权的设备，自动补上可靠的
Docker/Python 归属，让现有首页精选也能显示另一台设备的服务。不会额外申请权限或发起模型请求。

## 证据、范围与限制

旧 Coordinator 严格拒绝额外字段；已有 Gateway 能认证节点并返回脱敏监听与 Docker 发布记录。
本阶段复用这些工具，不修改目录协议或数据库，也不通过未经认证的服务地址猜名称。
只匹配同一节点、服务 ID、协议、绑定地址和端口；无权限、离线、过期、截断或冲突时不使用旧名称冒充新事实。
不读取命令行、环境、业务正文，不更改服务身份、批准指纹、网络或生产部署。

Python 运行程序不等于脚本用途；Docker 名称来自实际容器记录，不编造“照片备份”等业务解释。
静态单端口观察保持原有边界。没有 Gateway 授权的目录设备仍可看完整记录，但不能自动获得归属。

## 顺序与完成标准

1. 复用本机归属规则，增加有界远端观察；每周期最多 4 台、单台最多 10 秒、展示证据有效期 90 秒。
2. 接入两端既有后台周期与总览，只补展示名称，不改变 Incident 或 Operation 授权。
3. 验证精确身份、旧版本缺能力、撤权/离线/过期/失败、预算和两端工厂装配。
4. 隔离回归、截图/接口证据、提交推送，一个实现 PR；以最终完整 CI 与合并为完成条件。

## 实施与最终结果

本机与远端共用精选函数；远端默认不排除碰巧与本机相同的进程号。目录服务必须具有按真实节点、协议、
绑定地址和端口生成的身份，才接受归属。后台先验证已授权 Gateway 的节点身份与平台，再读取监听；
Docker 仅在允许能力中读取。无权限、不支持或依赖不可用时，不新增批准请求、不调用额外工具。

名称只在内存保存，不加入 Coordinator 协议、数据库或持久化快照。每轮轮转最多四台、单台十秒；
目录离线、撤销、陈旧、服务停止/移除、身份变化或九十秒过期时撤掉名称。观察失败清除旧名称；
服务原来的未知、停止、访问待确认等状态不被名称覆盖。GET 页面只读内存，不同步查询远端。

  失败/截断/无权限/无能力/无依赖、目录撤销/离线/陈旧/过期、停止/移除、四台轮转、取消及两端工厂接入。
