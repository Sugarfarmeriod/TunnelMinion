# TunnelMinion 威胁模型

## 范围

本威胁模型覆盖只读诊断和首个 L2 写路径“临时共享本机 HTTP 服务”，包括本地 Web UI、
模型 Provider、候选计划、确定性 Tool/Operation Runtime、目标节点授权、租约、资源所有权、
请求节点验证和恢复，以及 Coordinator 节点注册、目录、短期 assertion、撤销和缓存降级。
自动管理 WireGuard、通用 TCP、服务重启、Docker 控制、公开共享和企业 RBAC 不属于当前范围。

## 资产与信任边界

核心资产包括模型与节点凭据、私有网络拓扑、本机系统元数据、对话与记忆、工具策略，
以及两个节点的完整性和可用性。主要信任边界如下：

```text
本地浏览器
    | 环回 HTTP
本地 Runtime ---- 模型 API（不可信外部服务）
    | 受控适配器
操作系统 / Docker / WireGuard
    |
    | WireGuard 上经过应用认证的请求
远端 Tool Gateway ---- 远端适配器与不可信工具数据
```

WireGuard 负责网络 peer 认证，但不能替代应用认证或工具授权。模型输出、用户文本、进程名、
容器元数据、HTTP 文本和所有远端响应都属于不可信输入。

## 威胁与控制措施

| 威胁 | 示例 | 预防措施 | 检测与安全失败 |
|---|---|---|---|
| 模型提示注入 | 容器标签要求忽略策略并执行命令 | 工具结果标记为不可信数据；模型只能看到经过策略过滤的工具集；系统不存在 shell/代码工具 | 注入 fixture 不得改变允许工具集；记录脱敏策略事件 |
| 工具参数注入 | 模型加入命令参数、shell 语法、未知字段或端口 70000 | Pydantic schema 禁止额外字段并在适配器调用前校验范围；适配器只使用固定 API/参数列表 | 返回 `invalid_argument`，不得产生系统调用 |
| 编造工具或版本 | 模型编造 `restart_service` 或请求不兼容 schema | 注册表精确匹配、只读允许列表、主版本兼容检查 | 返回 `tool_not_found`、`operation_not_supported` 或 `version_incompatible` |
| 未认证远端访问 | 局域网进程或未知 WireGuard peer 调用 B | 网关仅绑定配置的 WireGuard 地址；独立节点凭据和 peer 允许列表 | 调度前返回 `unauthenticated`；只记录无秘密的审计元数据 |
| Coordinator 身份伪造 | 重放 enrollment、伪造 assertion、算法降级或跨 network 使用 | 一次性原子消费 token；refresh 哈希；Ed25519、固定 key ID/指纹、audience/network/node/protocol/TTL 绑定 | 重放返回 401；未知 key、错误 audience、篡改和跨 network 全部失败关闭 |
| 撤销或陈旧目录绕过 | Coordinator 离线后继续把撤销节点或旧 endpoint 当实时节点 | Gateway 仅使用有 TTL 的本地授权缓存；撤销修订到达立即拒绝；缓存过期 managed 身份失败关闭 | 页面显示 stale/offline/managed-auth-expired；static peer 不被目录静默覆盖 |
| 节点时钟轻微偏差 | assertion 在 A 签发后因 B 慢约 1 秒而被误判“来自未来” | 只对 `issued_at` 和 key 激活时间允许固定 5 秒未来偏差；固定 120 秒 TTL 与过期判断不延长 | 超过 5 秒仍拒绝；真机记录秒级差值但不保存 assertion |
| 跨 namespace 访问 | A 请求 B 的对话、模型配置或私有记忆 | 远端 schema 仅暴露批准的系统元数据；存储必须校验用户/网络/节点 namespace | 返回 `forbidden`；建立 namespace 隔离回归测试 |
| 秘密泄露 | 异常、日志、导出、模型 prompt 或 API 响应包含 API key | 操作系统凭据存储、允许列表序列化、秘密类型不进入通用模型、禁止读取 WireGuard 私钥 | 测试与发布检查扫描秘密；未知导出字段默认拒绝 |
| 拒绝服务 | 重复调用昂贵工具、巨大结果、慢 peer 或无限模型循环 | 每个 run 具有模型/工具预算、速率限制、并发限制、超时、取消和字节限制 | 返回明确超时/大小/速率错误；保留有界审计元数据 |
| 过期或伪造证据 | 旧端口状态被视为当前状态，或 B 返回畸形数据 | 证据时间与有效期、来源节点和 `tool_run_id`、schema 校验、认证传输 | 标记证据过期/无效；缺少必要证据时回答“未知” |
| 错误或越权记忆 | 未确认、过期、已删除或其他用户/节点/任务的记忆进入 prompt | 先按用户、网络、节点、任务和安全域硬过滤，再检查确认、有效期、修订链和 tombstone | namespace 泄漏、错误注入和删除残留任一非零即阻断发布 |
| 大结果污染上下文 | 日志或二进制结果耗尽窗口并夹带提示注入或凭据 | 分项预算；超限正文进入受控制品；模型只见脱敏预览和权限引用 | 完整正文、秘密或自动制品展开进入快照即阻断发布 |
| Prompt 无版本漂移 | 直接修改生产提示而未更新版本，导致结果不可复现 | 仓库注册表固定 prompt ID、语义版本、内容哈希、允许输入和中文变更说明 | 版本覆盖率不足或哈希不匹配时门禁失败 |
| 模型或 Context 故障扩散 | Builder、摘要或模型超时导致资源面板、拒绝或撤销也不可用 | AI 推理失败即停止本 run；确定性工具 API、治理与恢复路径独立 | 按 Context、Prompt/Model、Harness/Tool、Governance 脱敏归因 |
| 本地 Web 暴露 | 管理面板监听所有接口 | 仅绑定 `127.0.0.1` 和 `::1`；禁止复用远端网关监听器 | MVP 请求非环回面板地址时启动失败 |
| 逃逸只读边界 | 适配器修改 WireGuard、Docker、服务、文件、路由或端口转发 | 不提供修改型适配器方法；使用固定只读命令/API；真机验收前后采集快照 | 任何系统状态变化都是阻断发布的安全失败 |
| 模型降低操作等级 | 模型把临时共享伪装成 L0 并声称已执行 | 操作等级由注册表固定为 L2；模型只写四个说明字段，不持有写适配器 | 服务端拒绝等级、计划版本或证据不匹配 |
| 过宽或过期授权 | 旧批准被用于另一个 peer、服务、端口或时长 | 一次性批准绑定 operation；预授权完整约束 peer、工具、服务指纹、端口、时长和有效期 | 任一维度越界重新进入待批准 |
| 服务替换竞态 | 批准后环回端口被另一个进程占用 | 执行前重新读取监听 PID/进程名并重算服务指纹，再做有界 HTTP 探测 | 指纹或端点变化返回 `service_changed`，不创建入口 |
| 临时入口泄露 | token 进入 URL、日志、模型或导出 | 高熵 token 只进秘密存储和 A 的验证内存；浏览器由 A 环回桥注入请求头 | 秘密扫描与错误凭据测试；普通输出仅显示凭据已配置 |
| 错误资源清理 | 恢复器删除用户原有代理或同端口新进程 | 每个资源保存 owner fingerprint；停止和删除前再次匹配 | 不匹配进入 `cleanup_failed`，给出人工建议而不误删 |
| 假成功 | B 创建代理后自行声称成功 | 必须由 A 沿真实路径回调验证；A 离线、超时、认证失败或状态码不符立即回滚 | “验证失败却报告成功”为零容忍发布失败 |

## 安全不变量

- 模型不得直接执行 shell、Python、动态导入或文件写入。
- 模型工具集中只能出现已经注册的 L0 只读工具；L2 不进入普通 Tool Runtime。
- 每次本地或远端调度都必须执行认证、授权、参数校验、超时和结果限制；模型不得覆盖。
- 单个依赖缺失或权限不足只能使对应能力降级，不得导致整个运行时失败。
- 实时状态结论必须引用有效证据；缺少证据时必须明确标记未知，禁止使用模型猜测。
- 现有 `HomeMac` 和 B 的 WireGuard 配置不得被创建、修改或删除。
- Coordinator 不得接收工具/操作正文、模型密钥、对话、记忆或 WireGuard 私钥，也不得代理数据面。
- managed 缓存到期必须失败关闭；static peer 不得被 Coordinator 配置删除或扩权。
- 模型不可批准、预授权、执行、撤销或清理操作；这些路径在模型不可用时仍必须工作。
- 禁止操作执行、安全边界绕过、凭据泄露、错误资源删除和假成功出现一次即阻断发布。

## 验证门禁

安全测试必须覆盖带提示注入的工具数据、未知工具、非法参数、未认证和未授权 peer、跨
namespace 读取、超大结果、超时与取消、日志/导出中的秘密模式，以及平台调用前后快照。
任何禁止操作成功执行或 L2 绕过授权，都属于 CI 与 A/B 真机验收的零容忍失败。

综合离线门禁还必须固定覆盖陈旧状态、长 thread、错误记忆、prompt injection、大结果、
namespace 越权和删除记忆残留。真机验收必须证明模型从本次候选集合动态选工具、A 对指定目标
实际探测、实时证据覆盖旧历史，并在回答中引用工具证据；不能把“模型说已检查”当成通过。

## 剩余风险

已授权本机用户可以查看本机元数据，已授权 peer 可以查看工具策略明确允许的元数据。
应用无法完全阻止操作系统账户或模型 Provider 已被攻破的情况。MVP 通过凭据仅保存在所属
节点、最小化返回数据、排除写操作工具以及使用审计 ID 追踪远端操作来限制影响范围。
