## ADDED Requirements

### Requirement: Agent 自动枚举本机监听服务

Agent SHALL 周期性枚举本机 TCP 和 UDP 监听端点，并在平台权限允许时关联进程名称。Agent MUST 只枚举本机状态，不得默认扫描物理局域网或远端节点端口。

#### Scenario: 发现新的监听端口

- **WHEN** 本机进程开始监听一个端口并到达下一次发现周期
- **THEN** Agent 在本机服务快照中新增包含协议、地址、端口、来源和最后观测时间的记录

#### Scenario: 无权读取进程信息

- **WHEN** Agent 能观察监听端口但没有权限读取所属进程
- **THEN** Agent 仍记录该端口，并将进程字段标记为未知，而不是中止整个扫描

### Requirement: Agent 可选读取 Docker 元数据

当本机 Docker API 可用且 Agent 获得只读访问权限时，Agent SHALL 读取运行中容器的名称、镜像、标签和已发布端口以增强服务记录。Agent MUST NOT 读取容器环境变量、文件内容或执行容器控制操作。

#### Scenario: Docker 容器发布 HTTP 端口

- **WHEN** 运行中容器具有可见名称、镜像和已发布端口
- **THEN** Agent 将容器元数据与对应监听服务关联，并保留元数据来源

#### Scenario: Docker 不可用

- **WHEN** 设备未安装 Docker、Docker 未运行或 Agent 无权读取 Docker API
- **THEN** 基础端口发现继续工作，并报告 Docker 来源不可用而不是把整个扫描标记为失败

### Requirement: 服务探测受到安全预算限制

Agent MAY 对已发现的本机端点执行允许列表中的低风险协议探测，但 MUST 使用严格超时、并发限制和响应大小限制。Agent MUST NOT 读取业务请求正文、用户文件或尝试认证受保护服务。

#### Scenario: HTTP 服务返回可识别元数据

- **WHEN** 允许的 HTTP 探测在限制时间内返回标题或响应头
- **THEN** Agent 可以使用这些元数据推测服务类型，并记录推测来源和置信度

#### Scenario: 探测超时或返回过大响应

- **WHEN** 服务未在限制时间内响应或响应超过读取预算
- **THEN** Agent 终止该探测并保留基础端口记录，不影响其他服务发现

### Requirement: 区分远程可达与仅本机服务

Agent MUST 根据监听地址和受管虚拟网络状态标记服务可访问性。只监听环回地址的服务 SHALL 显示为 `local-only`，不得向其他节点提供可直接打开的虚拟网络链接。

#### Scenario: 服务只监听环回地址

- **WHEN** 服务仅监听 `127.0.0.1` 或 `::1`
- **THEN** 服务目录将其标记为 `local-only`，远端面板可以看到元数据但不能获得“打开”操作

#### Scenario: 服务监听可从虚拟网络访问的地址

- **WHEN** 服务监听通配地址或受管虚拟网卡地址，且节点网络状态可用
- **THEN** 服务目录将其标记为可从组网访问，并生成相应虚拟地址和端口信息

### Requirement: 协调服务同步带新鲜度的服务目录

Agent SHALL 将版本化服务快照同步给协调服务。协调服务 MUST 按节点和服务稳定 ID 保存最新快照，并根据最后更新时间将记录标记为在线、过期或离线。

#### Scenario: 服务停止监听

- **WHEN** 后续完整快照不再包含此前存在的服务
- **THEN** 协调服务将该服务移出活动目录或标记为已停止，其他节点不再获得可访问操作

#### Scenario: 节点离线导致目录过期

- **WHEN** 节点超过配置的离线阈值未更新服务快照
- **THEN** 其服务被标记为离线或过期，且 UI 不把这些服务表示为当前可用

### Requirement: 基础服务发现不依赖大模型

端口枚举、Docker 元数据、允许的协议探测、目录同步和基础展示 MUST 在未配置任何大模型 API 时正常工作。

#### Scenario: 用户未配置大模型 API

- **WHEN** Agent 没有大模型提供商或 API Key 配置
- **THEN** 系统仍生成确定性的基础服务目录，并使用已知元数据或“未知服务”作为显示结果
