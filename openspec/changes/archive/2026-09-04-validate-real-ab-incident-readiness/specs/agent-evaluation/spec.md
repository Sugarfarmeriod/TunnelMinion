## ADDED Requirements

### Requirement: 真实 A/B 验收必须证明环境不变并清理自有资源

真实 A/B 验收 MUST 在执行前完成只读预检，MUST 将生产模型、Gateway、既有隧道和可观察网络状态的前后结果写入脱敏报告，并 MUST 在成功或失败后停止和删除验收自有的临时进程、监听、目录与凭据。验收不得为获得完整系统正文而请求提权，也不得把权限不足的空输出报告为已验证事实。

#### Scenario: 模型服务当前离线

- **WHEN** 真实 A/B 验收开始时生产模型端口不可达而其他必要网络基线有效
- **THEN** 验收继续验证无模型降级，并只在结束时模型端口仍保持不可达、生产 Gateway 与网络基线未改变且临时资源已清理时通过

#### Scenario: 只读系统命令权限不足

- **WHEN** 非特权 macOS 账户不能读取完整 PF 或防火墙正文
- **THEN** 报告保存稳定的不可用状态或返回码，不请求 `sudo`、不保存配置正文且不把缺失证据解释为状态不变

#### Scenario: 验收中途失败

- **WHEN** 远端依赖、临时应用或断言在执行期间失败
- **THEN** 验收仍停止自有进程并删除经过固定前缀校验的临时资源，同时保存不含凭据的失败分类
